# RED ZONE 3D

Godot 4 Android FPS prototype.

## Play
Open this repository in Godot 4.4 or newer and run `scenes/main.tscn`.

## Controls
- Android: hold the left half of the screen to move; drag the right half to aim.
- Tap FIRE to shoot and RELOAD to refill ammunition.
- Desktop: WASD to move; mouse to aim. FIRE is an on-screen button.

## Android build
A GitHub Actions workflow attempts to export a debug APK on pushes to main and manual runs. Download the APK from the workflow's Artifacts only after the build succeeds.

This is an early playable prototype with procedural placeholder geometry and enemy capsules. Final realistic art, sound, and release signing are not included yet.
